A Real Distro, Not a Wrapper

Kernel: Cygwin

A UserLand Linux distribution: Cygwin as the kernel, a developer-curated userland — bash, vim, git, curl, gcc toolchains and apt-cyg package management, all bundled.

Zero Host Pollution

npm / pnpm / pip / playwright / Go module caches, Gradle user dirs, Ruby gems — everything stays inside the Komandare tree. Delete the folder and the host looks untouched.

kRun · Launch IDEs with Env

kRun code . — injects the complete toolchain before launching any third-party program. VSCode and other IDEs see the whole Komandare environment.

Portable Modules

Toolchains are organized as portable modules (Module/), installed and removed by kmod-setup in one command. The whole tree moves freely — even across drives.

Quick Start

Launch kmd

Double-click kmd.exe. Prefers Windows Terminal; falls back to the bundled ConEmu.

First Boot

The first launch opens the kmd-welcome full-screen TUI wizard to pick and install modules.

Manage Modules

kmod-setup install python3x — add or remove toolchains anytime.

Take It Anywhere

Copy the whole tree anywhere; kInitrd.cmd re-anchors all paths automatically.

DIY — Build Your Own Modules

1Drop It In

Toss any portable software into Module/<name>/ — the folder name is the module name. A module is just a folder; no manifest needed.

2Register

kmod-setup install <name> generates a Config/Init.d/NN-<name>.cmd loader; the module joins PATH on next boot.

3Pack & Share

kmod-setup export <name> produces a .kmp package (a zip with kmp.ini + loader.cmd + module/) — send it to anyone to install.

4Distribute & Update

kmod-setup mirror switches download sources; users run kmod-setup install -r <name> to pull from the registry, and kmod-setup update checks remote versions with sha256 verification.

komandare —— kmd
demo@MYPC ~ $ kmod-setup install mytools 20 mytools 1.2.0 "Demo Labs" kmod-setup: registered mytools v1.2.0 (Demo Labs) at priority 20 module : C:\Komandare\Module\mytools loader : C:\Komandare\Config\Init.d\20-mytools.cmd demo@MYPC ~ $ kmod-setup export mytools mytools-1.2.0.kmp kmod-setup: exported mytools v1.2.0 -> C:\Komandare\mytools-1.2.0.kmp payload: Module/mytools (14.2M) demo@MYPC ~ $ kmod-setup install mytools-1.2.0.kmp kmod-setup: installed mytools v1.2.0 (Demo Labs) module : C:\Komandare\Module\mytools loader : C:\Komandare\Config\Init.d\10-mytools.cmd kmod-setup: loader executed

You can also hand-write loaders — NN-*.cmd files under Config/Init.d/ run in 00–99 order at boot; module env vars, junctions and cache dirs all belong there. It is the standard way to extend Komandare.

Unixlike/Cygwin userland: bin/, usr/, kbin/ (built-in commands), etc/, home/
