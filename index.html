快速开始

启动 kmd

双击 kmd.exe。优先使用 Windows Terminal，缺失时回退到内置 ConEmu。

首次引导

首次启动进入 kmd-welcome 全屏 TUI 向导，选择并安装所需模块。

模块管理

kmod-setup install python3x —— 之后随时按需增删工具链。

带走环境

整个目录可拷贝到任意位置，kInitrd.cmd 自动重新锚定路径。

DIY —— 拼装你自己的模块

1放进去

任何绿色软件丢进 Module/<name>/ —— 目录名就是模块名。模块即文件夹，无需清单。

2注册

kmod-setup install <name> 生成 Config/Init.d/NN-<name>.cmd loader，下次启动模块自动进 PATH。

3打包分享

kmod-setup export <name> 导出 .kmp 包（zip，内含 kmp.ini + loader.cmd + module/），发给别人即可装。

4分发与更新

kmod-setup mirror 切换下载源；用户用 kmod-setup install -r <name> 从 registry 拉取安装，kmod-setup update 检查远程更新，sha256 校验保证完整性。

komandare —— kmd
demo@MYPC ~ $ kmod-setup install mytools 20 mytools 1.2.0 "Demo Labs" kmod-setup: registered mytools v1.2.0 (Demo Labs) at priority 20 module : C:\Komandare\Module\mytools loader : C:\Komandare\Config\Init.d\20-mytools.cmd demo@MYPC ~ $ kmod-setup export mytools mytools-1.2.0.kmp kmod-setup: exported mytools v1.2.0 -> C:\Komandare\mytools-1.2.0.kmp payload: Module/mytools (14.2M) demo@MYPC ~ $ kmod-setup install mytools-1.2.0.kmp kmod-setup: installed mytools v1.2.0 (Demo Labs) module : C:\Komandare\Module\mytools loader : C:\Komandare\Config\Init.d\10-mytools.cmd kmod-setup: loader executed

也可以手工编写 loader —— Config/Init.d/ 下的 NN-*.cmd 按 00—99 顺序在引导时执行，模块需要的环境变量、junction、缓存目录都可以写在这里 —— 这是扩展 Komandare 功能的标准姿势。

目录结构

路径角色
kmd.exe推荐启动器（Windows Terminal 优先，ConEmu 兜底）
kRun.exe在 kmd 环境内运行任意第三方程序
kBash.bat / kCmd.bat从任意终端进入 kmd 环境
kInitrd.cmd内核入口 —— 所有启动路径汇聚的引导加载器
Config/启动器配置、模块注册（Init.d/）、别名、缓存策略、服务
Module/工具链模块，每应用一个目录，由 Config/Init.d/*.cmd 注册
Binary/便携独立工具与包装（caddy、mitmproxy、cygwin-setup ……）
Unixlike/Cygwin 用户态：bin/、usr/、kbin/（内置命令）、etc/、home/
